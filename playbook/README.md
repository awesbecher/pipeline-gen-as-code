# playbook/

The canonical nine-engine content: one operating card per engine
(00 is the portfolio frame and CAC verdict). Each card carries the flow,
how the best teams run it, the benchmark, the stack, when to run it, the
first 90 days, and the tripwires. The skill and the generated plans read
from these files; the long-form web version lives at
https://www.wesbecher.llc/pipeline.
